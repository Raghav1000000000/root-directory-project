# Root Directory

Website of Root Directory, a software studio by Raghav Mittal (dev) and Aaditya Satam (partner).

Live: https://raghav1000000000.github.io/root-directory-project/

Plain HTML, CSS and JavaScript, no build step. Run it with `npx serve .`

- `index.html`: content
- `style.css`: styles (accent colour at the top)
- `main.js`: scroll, root line, work picker, contact form
- `scene.js`: the night scene
- `shots/`: project screenshots

This is separate from Raghav's personal site (https://raghav1000000000.github.io/). The case study links open there, and the contact form saves to the same Google Sheet with the source "studio contact form". Pushes to `main` publish through GitHub Pages. Changes are listed in [CHANGELOG.md](CHANGELOG.md).
